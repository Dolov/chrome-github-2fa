## 为什么选择这款 2FA 身份验证器？

双因素验证是保护账号安全的利器，本工具让你轻松生成并管理所有账户的动态验证码，提供：

- **多账户管理**，集中安全管理所有 2FA 账号
- 采用业界标准 **TOTP 算法**，自动生成 6 位动态验证码
- 支持 **二维码自动扫描**、**选区扫描**、**表单输入**、**上传二维码** 等多种密钥输入方式。
- 验证码自动刷新，时刻保持最新
- 本地加密存储密钥，确保隐私安全
- 简洁直观的界面，操作流畅，使用无门槛
- 完全开源，免费且可定制

## 主要功能

### 🔐 多账户管理

支持添加和管理任意数量的二步验证账户，随时快速获取验证码。

### 📷 二维码扫描 & 手动输入

支持通过摄像头扫描官方生成的 2FA 二维码，也可以手动输入密钥和账户信息。

### ⏲️ 自动刷新验证码

验证码自动每 30 秒更新，无需手动刷新，避免过期问题。

### 🔒 本地安全存储

所有密钥均本地加密保存，账号信息不上传任何服务器，安全可靠。

### 🌐 多平台支持

跨平台设计，支持多种设备和系统，不受限于 Chrome 浏览器。

### ⚡ 轻量简洁 UI

界面设计简洁直观，使用顺畅，专注于快速生成和复制验证码。

## 快速开始

1. **添加账户**
   点击“添加”按钮，扫描二维码或手动输入账号密钥。

2. **查看验证码**
   选择对应账户，应用会自动显示最新的 6 位动态验证码，并实时倒计时刷新。

3. **复制验证码**
   点击验证码即可复制，方便粘贴到登录页面完成二步验证。

4. **管理账户**
   支持编辑、删除账户，方便你随时维护和更新 2FA 配置。
